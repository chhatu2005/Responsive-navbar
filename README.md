# Responsive Navbar with Hamburger Menu

A responsive navigation bar built using HTML, CSS, and JavaScript.

The navbar displays horizontal navigation links on desktop screens and changes to a hamburger menu on mobile screens.

## Features

- Responsive navigation bar
- Desktop horizontal menu
- Mobile hamburger menu
- Open and close menu functionality
- Right-aligned mobile menu
- Smooth menu animation
- Transparent mobile menu background
- Responsive hero section
- Background image
- Get Started button
- Explore More button

## Technologies Used

- HTML5
- CSS3
- JavaScript
